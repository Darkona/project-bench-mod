# Changelog

## 0.2.0

- The bench, station and archive windows are now built with JDLib (on LDLib2) and look the same as before.
- JDLib travels inside the mod's jar, so players install nothing extra besides LDLib2.
- The blueprint slot always shows a faint blueprint when it is empty.
- New padlock icons for locked slots.
- Middle-click on a locked slot unlocks it, empty or not.
- Resource packs can tint the windows with named colours (`jdlib_palette`).

## 0.1.0

- First release: the bench, blueprints, archives, the station and the recipe viewer support.
